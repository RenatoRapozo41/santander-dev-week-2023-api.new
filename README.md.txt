# 💡 Santander Dev Week - Desafio Python

## 📒 Descrição

Este projeto simula a geração de mensagens personalizadas para usuários de um banco, utilizando lógica em Python e conceitos de Inteligência Artificial.

Devido à indisponibilidade da API oficial, foi utilizada uma abordagem alternativa com dados fictícios, garantindo o funcionamento completo da solução.

---

## 🤖 Tecnologias Utilizadas

* Python
* Lógica de programação
* (Opcional) Integração com IA

---

## 🧐 Processo de Criação

* Criação de uma lista de usuários simulando a API
* Implementação de regras de negócio para personalização
* Estruturação modular do projeto
* Separação entre dados, serviço de IA e execução

---

## 🚀 Resultados

O sistema gera mensagens personalizadas para cada usuário com base no saldo, simulando uma comunicação inteligente e automatizada.

---

## 💭 Reflexão

Mesmo sem a API oficial, foi possível desenvolver uma solução completa focando na lógica e estrutura do sistema, mostrando a importância da adaptabilidade no desenvolvimento.
